# 開発スケジュール（8週間）

## 1週目：準備 & 設計
- 開発環境セットアップ（GitHub, Docker, VS Code, AWS CLI, SAM CLI）
- 全体アーキテクチャ設計（Vue + Spring Boot on Lambda + Aurora Serverless + Secrets Manager）
- DB設計（ユーザテーブル、タスクテーブルなど最小構成）
---
- **学べること**
  - 開発環境構築力
  - クラウドを意識したアーキテクチャ設計
  - DBモデリングの基礎

## 2〜3週目：バックエンド開発
- Spring Boot API 作成（認証、ユーザ登録/ログインAPI、タスクCRUD）
- Secrets Manager 経由で DB 接続実装
- Docker でローカル動作確認
- 単体テスト
---
- **学べること**
  - REST API開発とセキュリティ
  - AWSでのセキュアなDB接続
  - Dockerによるローカル実行
  - 単体テストの実践

## 4週目：AWSデプロイ（バックエンド）
- SAM CLI で Spring Boot Lambda をデプロイ
- Aurora Serverless セットアップ
- Lambda → Aurora 接続確認
- API Gateway 経由でエンドポイント公開
---
- **学べること**
  - サーバーレスデプロイ
  - Aurora Serverlessの利用方法
  - API Gatewayの公開と管理

## 5〜6週目：フロントエンド開発
- Vue プロジェクト作成（Viteベース）
- ログイン画面 / タスク一覧画面 / タスク登録画面
- API と連携（Axios）
- Docker 化してローカルで動作確認
---
- **学べること**
  - Vueコンポーネント設計
  - 認証フロー実装
  - API連携と画面開発
  - フロントエンドのDocker化

## 7週目：CI/CD & 結合テスト
- GitHub Actions で CI/CD（push → 自動デプロイ）
- フロント（S3 + CloudFront にデプロイ）
- バックエンド（SAM で自動更新）
- E2Eテスト（ユーザ登録 → ログイン → タスク操作）
---
- **学べること**
  - CI/CDパイプライン構築
  - 静的サイトホスティングとCDN
  - E2Eテストによる品質保証

## 8週目：リリース & 発表準備
- 本番用デプロイ（AWS 無料枠で運用）
- 動作確認
- 発表用資料作成（構成図、開発手順、学びのまとめ）   
---
- **学べること**
  - 本番運用とリリース管理
  - 成果のプレゼンテーションスキル
  - 開発の振り返りと知識定着
