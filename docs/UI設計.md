## ページ一覧（最小構成）
1. ログインページ
   - ユーザが email / password を入力
   - 成功 → JWT受け取り、ローカルストレージ保存
   - 失敗 → エラーメッセージ表示
2. タスク一覧ページ
   - ユーザに紐づくタスクを一覧表示
   - タスクのステータス（TODO / IN_PROGRESS / DONE）を視覚的に区別
   - 新規登録ボタン / 編集ボタン / 削除ボタン
3. タスク登録/編集ページ
   - フォーム入力：title, description, status, dueDate
   - 登録時は POST /api/tasks
   - 編集時は PUT /api/tasks/{id}

| ------------- | ------- | ------------------------ |
